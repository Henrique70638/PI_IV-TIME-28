# CULT+ 🌱

**Plataforma de conexão entre produtores domésticos e pessoas interessadas em produtos cultivados em casa.**

## 📌 Sobre o projeto

O **CULT+** é um projeto desenvolvido para a disciplina de **Projeto Integrador IV (PI IV)**, do curso de Engenharia de Software da **Pontifícia Universidade Católica de Campinas (PUC-Campinas)**.

A plataforma tem como objetivo conectar pessoas que possuem excedentes de produtos cultivados em casa, como frutas, verduras, legumes e plantas, com pessoas interessadas em comprá-los ou recebê-los.

A proposta é incentivar o consumo consciente, reduzir o desperdício de alimentos, valorizar a produção doméstica e promover a conexão entre pessoas da comunidade.

Por meio do aplicativo, os usuários poderão divulgar seus produtos disponíveis, encontrar ofertas próximas e estabelecer conexões com outros participantes da plataforma.

## 🎯 Objetivos

- Reduzir o desperdício de alimentos e produtos cultivados em casa.
- Facilitar a divulgação de excedentes de produção doméstica.
- Conectar ofertantes e interessados em produtos.
- Incentivar práticas sustentáveis e o consumo consciente.
- Promover a economia colaborativa e o compartilhamento entre pessoas.

## ⚙️ Tecnologias utilizadas

O projeto utiliza diferentes tecnologias para o desenvolvimento do aplicativo mobile, do servidor e do backend.

| Tecnologia | Aplicação |
|---|---|
| **Dart** | Linguagem de programação do aplicativo mobile. |
| **Flutter** | Framework utilizado para o desenvolvimento da interface mobile. |
| **Java** | Desenvolvimento do servidor e da comunicação entre os componentes do sistema. |
| **TypeScript** | Linguagem utilizada no desenvolvimento do backend. |
| **Node.js** | Ambiente de execução do backend. |
| **MongoDB** | Banco de dados para armazenamento das informações da plataforma. |
| **Git e GitHub** | Controle de versão e colaboração entre os integrantes da equipe. |

## 🏗️ Arquitetura do projeto

O CULT+ é organizado em três componentes principais:

### 1. Aplicativo Mobile — Flutter/Dart

Responsável pela interface com o usuário e pelas funcionalidades disponíveis no aplicativo.

Suas responsabilidades incluem:
- Cadastro e autenticação de usuários.
- Visualização e gerenciamento de perfis.
- Publicação de produtos disponíveis.
- Consulta de produtos publicados.
- Comunicação com os serviços do sistema.

### 2. Servidor — Java

Responsável pela implementação da camada de servidor, permitindo a comunicação entre o aplicativo mobile e os serviços do sistema.

Seu desenvolvimento também contempla a estruturação da comunicação cliente-servidor.

### 3. Backend — TypeScript/Node.js

Responsável pela implementação da lógica de backend e pelos serviços necessários para o funcionamento da plataforma, incluindo o processamento de requisições e a comunicação com o banco de dados.

### 4. Banco de dados — MongoDB

Utilizado para armazenar e organizar os dados da aplicação, como informações dos usuários, produtos publicados e demais informações necessárias para o funcionamento da plataforma.
